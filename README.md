# Classical Music Themed Escape Room

Welcome to the Classical Music Themed Escape Room! This is an interactive web-based escape room game where each room is inspired by elements of classical music. Solve puzzles, explore different rooms, and test your music knowledge!

Click here to see the live site: https://hannahro15.github.io/classical-music-themed-escape-room/

## Features

- Multiple themed rooms, each with unique puzzles
- Classical music concepts and trivia
- Engaging visuals (all room images generated by Google Gemini)
- Built with React and Vite for a fast, modern experience

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v20.19+ or v22.12+ (required by Vite 7)
- [npm](https://www.npmjs.com/), which comes with Node.js

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/hannahro15/classical-music-themed-escape-room.git
   cd classical-music-themed-escape-room
   ```
   If you want to contribute, fork the repository first and clone your fork instead.
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

Start the development server:

```bash
npm run dev
```

Then open [http://localhost:5173/classical-music-themed-escape-room/](http://localhost:5173/classical-music-themed-escape-room/) in your browser.

### Deploying

Publish the site to GitHub Pages:

```bash
npm run deploy
```

Commit your changes first. The deploy stops with "Commit your changes before deploying" if there are uncommitted changes, so the live site always matches a commit.

## Project Structure

- `src/` - React components, styles, and assets
  - `components/` - The home page
  - `rooms/` - Individual rooms and their puzzles
  - `data/` - Room data
  - `assets/` - Room images
- `public/` - Static files
